This report is generated by AI and should be reviewed by a human before use. Always verify the fee data and calculations before making any decisions based on this report.

## Step 1. Collect Portfolio and Fee Information

Gather the following from the user or wiki files (read `.claude/wiki/` first to narrow scope):

**Portfolio data:**
- Portfolio name(s) and ID(s)
- Holding identifiers (APIR code or ASX code)
- Allocation of each holding (as decimal weight, e.g., 0.16 not 16)
- IM (Investment Manager) fee rate in percent as decimal (e.g., 0.45)
- RE (Responsible Entity) fee rate in percent as decimal (e.g., 0.08)

**Fund fee data (for each holding):**
- Unit ID (APIR/ASX code)
- Unit Name
- Management fees and costs (%)
- Cash investment fee (%) : this is 0 for all units except `CASHACCT` which is 0.14% (0.0014)
- Performance fees (%)
- Gross transaction costs (%)
- Buy spread (%)
- Sell spread (%)
- Rebate (%)
- PDS URL

All fee values must be expressed as decimals (e.g., 0.07 not 7).

## Step 2. Search Fund Fees and Validate Data

### Step 2a: Lookup Fund Fees from CSV Reference

Use the team's unit fee reference file (`.claude/skills/fee-analysis/references/UnitFee.csv`) to lookup fee data.

**Lookup process:**
```bash
python .claude/skills/fee-analysis/scripts/lookup_unit_fees.py <unit_id_1> <unit_id_2> ...
```

This returns JSON with:
- `found`: Units found in CSV with complete fee data (8 fee components + PDS URL)
- `missing`: Unit IDs not in CSV

**For missing units:** 
- Research on public domain sources (fund fact sheets, PDS, manager websites, ASX, Morningstar, etc.)
- Document all 8 fee components + PDS URL
- Add the new row to `.claude/skills/fee-analysis/references/UnitFee.csv`
- You or I can do the web search and CSV update; confirm when all units are found

**Fee data required for each holding:**
- Unit ID (APIR/ASX code)
- Full Unit Name
- Management fees and costs (%)
- Cash investment fee (%)
- Performance fees (%)
- Gross transaction costs (%)
- Buy spread (%)
- Sell spread (%)
- Rebate (%)
- PDS URL

All fee values must be expressed as decimals (e.g., 0.07 not 7%).

### Step 2b: Validate Collected Data

Before proceeding to Step 3, validate that all collected data satisfies these rules:

| Field | Rule | Validation |
|---|---|---|
| `im_fee_bps`, `re_fee_bps` | Decimal percent < 1 (e.g., 0.45) | true/false |
| All fund fees (mgmt, cash_inv, perf, transaction, buy_spread, sell_spread, rebate) | Decimal percent < 1 (e.g., 0.07) | true/false |
| Tax rates (GST_RATE, IM_RITC, RE_RITC) | Decimal percent < 1 (e.g., 0.10, 0.75) | true/false |
| `allocation` per holding | Decimal weight > 0 and ≤ 1 (e.g., 0.16, not 16) | true/false |
| Per-portfolio allocations | Must sum to 1.0 (±0.001 tolerance) | true/false |
| `pds_url` per fund | Non-empty string; must point to specific PDS page (not homepage or search results) | true/false |

If any value fails validation, STOP and ask the user to correct it. Do NOT proceed to step 3 until all values pass.

## Step 3. Write Configuration

Write the validated data to a JSON config file at:
```
.claude/skills/fee-analysis/config/tmp_config_YYYYMMDD.json
```

Use this schema:
```json
{
  "series_name": "iShares Enhanced Portfolios",
  "tax_data": {
    "GST_RATE": 0.10,
    "IM_RITC": 0.75,
    "RE_RITC": 0.55
  },
  "portfolios": [
    {
      "portfolio_name": "Balanced Portfolio",
      "series": "NTH0001",
      "im_fee_bps": 0.45,
      "re_fee_bps": 0.08,
      "holdings": [
        {
          "apir": "VAS",
          "portfolio_id": "NTH0001",
          "portfolio_name": "Balanced Portfolio",
          "fund_name": "Vanguard Australian Shares Index ETF",
          "allocation": 0.16
        }
      ]
    }
  ],
  "fund_fees": {
    "VAS": {
      "mgmt": 0.07,
      "cash_inv": 0.0,
      "perf": 0.0,
      "transaction": 0.0,
      "buy_spread": 0.0,
      "sell_spread": 0.0,
      "rebate": 0.0,
      "pds_url": "https://www.vanguard.com.au/products/details/vanguard-australian-shares-index-etf-vas"
    }
  }
}
```

**Critical:** Each `pds_url` must be the specific fund product page URL from the manager's website, not a homepage or search page.

## Step 4. Calculate Fees (Shell Out)

Shell out to the Python script:
```bash
python .claude/skills/fee-analysis/scripts/generate_fee_analysis.py \
  .claude/skills/fee-analysis/config/tmp_config_YYYYMMDD.json
```

This generates:
- **Excel workbook:** `.claude/output/Fee Analysis - [Series] - [Date].xlsx` with 3 sheets:
  1. Fee Summary (with Excel formulas)
  2. Component Table (per-fund fee breakdown)
  3. Portfolio Holdings (allocations)
- **Markdown summary:** `.claude/wiki/Fee Analysis - [Series] - [Date].md`

The config JSON is retained at `.claude/skills/fee-analysis/config/` for audit purposes.

Report both output file paths to the user.
